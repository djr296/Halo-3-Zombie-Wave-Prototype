# Contributing

This archived prototype is open for forks and community continuation.

## Ground rules

- Commit only original scripts, documentation, configuration, and source art
  that you have the right to redistribute.
- Do not commit extracted Halo tags, compiled maps, textures, sounds, models,
  or other Microsoft game assets.
- Keep the five `fs_wave_01` through `fs_wave_05` scenario references stable,
  or update the naming contract and validator together.
- Explain any required Sapien or Guerilla work in the pull request.
- Run `tools\Test-FloodSurvivalProject.ps1` before submitting changes.

## Suggested workflow

1. Fork the repository.
2. Create a focused branch.
3. Make and document the change.
4. Validate the source package.
5. Open a pull request describing the in-engine test results.
